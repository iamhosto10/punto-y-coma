# Punto & Coma — Landing Page

Landing page simple para **Punto & Coma**, restaurante de salchipapas en
Valledupar. Hecha con Next.js, Tailwind CSS y shadcn/ui, usando la paleta
de marca (negro + amarillo-dorado) y contenido tomado de su Instagram
([@puntoycoma.vpar](https://www.instagram.com/puntoycoma.vpar/)) y de su
menú digital.

## Contenido

- Logo y colores de marca
- Selección de platos destacados (no el menú completo)
- Direcciones de las dos sedes (Mayales y Norte)
- Botón de pedido que redirige al menú completo en vinapp.co
- Botón de redirección a Instagram
- Fotos del local y de producto

## Desarrollo

```bash
npm install
npm run dev
```

## Build de producción

```bash
npm run build
npm run start
```
